# Features

This document outlines exisiting and planned features for the project. Many of these features are aimed enhacing productivity and user experience for neuridivergent users.

## Existing Features
- [TickTick](https://ticktick.com/) integration (required)

## Planned Features
- Basic task management (complete, edit and delete tasks)
- Subroutines feature for grouping related tasks and creating routine templates
- Focus/Zen mode for viewing 1-2 tasks with a minimalist interface
- New task popup for quick task addition
- Batch task creation for quickly adding multiple tasks with auto-incrementing due time
- Animations and transitions for satisfying user interactions, like exploding tasks when completed

## Suggested Features
- Visual scheduling, including drag-and-drop support for rescheduling and rearranging tasks
- Sound effects to go along with animations and interactions
- Auto time blocking based on task priorities and deadlines
- Use language models to auto prioritize and/or create subtasks (kinda like "Magic ToDo" in [Goblin Tools](https://goblin.tools/))
- Notifications that adapt based on user behavior and task urgency
- "What should I do next?" feature that suggests tasks based on context and priorities
- Extensive personalization options, including themes and layouts
