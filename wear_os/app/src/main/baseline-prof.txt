# Baseline profile for Subroutine Wear OS app.
#
# ART uses this file to pre-verify and AOT-compile these classes and methods
# before the app is first run, eliminating the VerifyClass pauses on the main
# thread that cause scroll jank on Wear OS hardware.
#
# Format:
#   L<class>;                          — pre-verify the class
#   PLm<class>;-><method>(<sig>)<ret>  — pre-compile (interpret-only profile)
#   HSPLm<class>;-><method>(<sig>)<ret> — hot + startup + post-startup compile
#
# We cover:
#   1. Our own presentation layer
#   2. Wear Compose Material3 scroll/transformation hot path
#   3. Wear Compose Foundation lazy layout engine
#   4. Compose UI core (measure/layout/draw)
#   5. Compose runtime (recomposer, slot table, snapshot)
#   6. Kotlin coroutines (StateFlow, collect)
